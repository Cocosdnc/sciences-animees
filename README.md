# Dans la diode laser

Animations interactives pour comprendre une diode laser, du pointeur jusqu'aux atomes : couches p/n, émission stimulée, nature ondulatoire de l'électron (Davisson et Germer), orbitales, liaison Ga–P, couleur des LED et LED blanche.
